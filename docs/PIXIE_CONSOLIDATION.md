# PIXIE consolidation release

Approved direction: Dominique Devereaux, 18 October 2026. This is the release
record under the existing ecosystem architecture, not a replacement architecture.

## Scope

1. Record audiences, implementation homes, capabilities and gaps.
2. Focus the Companion, Holdings, Creator OS and 50 Ways public explanations.
3. Remove duplicated introductions and relocate detailed roadmaps without losing history.
4. Check local navigation, supported handoffs and publication separately.
5. Provide a bounded paid-pilot proposal and explicit remaining decisions.

Keep existing hosting, repositories and visual identities. No new authentication,
private-data integration, recurring service or repository consolidation is authorized.

## Operating model

Remote studio first; low overhead; coworking or temporary space when needed.
Owner and contributor compensation belongs in paid-project budgets. No spending,
hiring, partner commitment or revenue promise is authorized by this release.
Speaking and partner discovery follows completion of the release. Public outreach
requires a separate instruction; preparing a shortlist is not contacting anyone.

## Capability boundary

Companion tools prepare drafts and read explicit public GitHub checkpoints.
GitHub stores shared records only after submission. Creator OS prepares local
drafts and manual sharing text. Holdings provides synthetic scenario and preview
tools. Discovery is read-only. Narrative Provenance stores local note metadata.
Cross-domain login, shared private storage and a unified live runtime are not
established. Public plugin installation remains a separate release milestone.

## Acceptance checks

- Contributor: choose a project, prepare a draft and resume a supplied submitted issue.
- Creator: prepare one piece, review attribution/permission/reporting context and export a draft or manual handoff.
- Partner: identify the studio offer, relevant demo and proposed pilot scope.
- Preserve 50 Ways artwork, palette, typography and layout.
- Verify local links and tests; report device/browser/accessibility limits.
- Distinguish source commit, deployment result and live observations.
- No claim of legal clearance, automatic publishing, paid positions or formal enrollment.

session, usable materials, observed barriers and a maintenance handoff. The first

with a defined audience and a budget. No partner is represented as interested.
